# Documentation research

Reviewed official repository pages 25 October 2026. This concerns presentation and installation documentation, not a comparative effectiveness benchmark.

| Source | Observed structure | UX Kit decision |
|---|---|---|
| [Superpowers](https://github.com/obra/superpowers) | Explains its process and provides harness-specific installation | State the workflow and distinguish agent install/runtime support |
| [Impeccable](https://github.com/pbakaus/impeccable) | Immediate quick start, specific capability/command descriptions and full-docs route | Put installation near the top and link detailed coverage |
| [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Searchable design resources, stack scope, installer and troubleshooting sections | Make task coverage and installation boundaries concrete |

UX Kit's positioning is practical UX judgment with evidence, proportionate changes and checks. It complements visual design/art-direction resources and engineering process skills. This is a scope distinction, not a claim that those skills lack UX judgment or that UX Kit outperforms them. No text, logo, artwork, badges, social-proof counts or unsupported compatibility matrix is copied.
