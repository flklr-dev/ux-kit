# Credits and related tools

UX Kit's source bibliography is in [Research and principles](foundations.md). Original explanations and examples are MIT-licensed; linked third-party works keep their original rights.

These independently developed tools address neighboring parts of agent-assisted work:

- [Superpowers](https://github.com/obra/superpowers): engineering workflow skills.
- [Impeccable](https://github.com/pbakaus/impeccable): design guidance and interface refinement.
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): design resources and stack guidance.

UX Kit focuses on task-specific UX judgment, proportionate changes, preservation and concrete checks. These scope descriptions do not imply endorsement or a comparative performance result.
