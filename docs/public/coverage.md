# What UX Kit covers

The installed library has **137 canonical entries, 15 topic guides, 12 feature guides and four workflows**. Counts come from the published metadata, not a marketing estimate. Entries include heuristics, standards/platform guidance, practical patterns and research methods; they are not 137 proven psychological laws.

## Start from the task

| Feature guide | Questions it helps an agent investigate |
|---|---|
| Accounts | Sign in, account creation, recovery, input effort |
| Onboarding and permissions | First use, contextual requests, denial and fallback |
| Forms and editing | Validation, draft save, pending edits, submit/retry |
| Checkout and payments | Known charges, unresolved fees, commitment and receipts |
| Subscriptions | Renewal, informed choice and cancellation |
| Search and filters | Scope, current criteria, empty/no results |
| Navigation | Labels, destinations, Back and direct links |
| Data tools | Comparison, expert density, tables and bulk work |
| Background work | Uploads, progress, interruption and retry |
| Offline and sync | Retained work, conflicts and uncertain results |
| AI review and bulk actions | Review/Apply, source facts, agency and partial outcomes |
| Settings | Privacy, preferences and automation scope |

The 15 topic guides connect cognition/choice, perception/grouping, targeting/interaction, learning/memory, motivation/complexity, usability/control, information architecture, forms/accounts, commerce/trust, data tools, content/localization, accessibility/inclusion, native/resilience, human–AI agency and research/evaluation.

## Principles with conditions

Fitts's law helps inspect effective targets and acquisition distance. Hick–Hyman helps investigate choice time under fitting conditions. Gestalt principles help inspect relationships and grouping. Recognition, feedback and error recovery help reduce unnecessary recall and correction effort. Accessibility and platform entries identify the scope of actual requirements.

Each entry includes application signals, interventions, limitations, a counterexample/conflict and checks. All 30 mapped Laws of UX concepts are addressed through entries, qualifications or merged aliases. Coverage does not mean every popular claim is accepted as a universal rule. For example, five navigation destinations is not a universal psychological maximum.

## Choose a workflow

| Mode | Outcome | Edit boundary |
|---|---|---|
| Design | Proposed task flow, states, tradeoffs and validation | Proposal; does not authorize product edits |
| Audit | A few prioritized, evidenced findings | Read-only |
| Implement | Authorized changes using the existing stack/components | Only the requested scope |
| Validate | Whether a supplied fix satisfies its checks | Inspect/test; does not independently authorize new fixes |

Whole-screen work reviews navigation, task hierarchy, copy/trust, controls, accessibility, adaptation, states/recovery and overlays. An area may be kept, unknown or outside scope. Useful imagery, promotion, familiar names and compact controls are preserved unless evidence justifies changing them.
