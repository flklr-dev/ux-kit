Before you start.

Does it work with my design skill?

Yes. Use UX Kit to reason about tasks, behavior and evidence alongside your visual design guidance. Tell your agent which skill owns which decision, and preserve your project’s existing design system.

Will it redesign everything?

It should justify each change and preserve useful behavior, copy, density, imagery and promotion. An audit is read-only. Implementation stays within the scope you authorize.

Is it just for websites?

The skill covers websites, web apps and native mobile flows. Platform-specific requirements stay scoped to their platform. A browser preview cannot prove native behavior.

What has been checked?

Repository structure, reference routing, installation and payload integrity have been checked. These checks do not establish universal effectiveness or full accessibility conformance. See the verification details.

Where do the principles come from?

The library links to original research where inspected, established usability guidance, W3C standards and platform documentation. Every entry includes its sources and limitations. Read about the foundations.
