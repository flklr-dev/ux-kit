**Explanation:** Continuation is one cue used in perceiving contours. For interface paths, inspect whether line continuity communicates the intended route.

**Signals:** Crossing timeline lines make it unclear which event belongs to which process.

**Interventions:** Use explicit labels and unambiguous junctions; verify the implied route in context.

**Limits:** The review's perceptual displays do not validate a specific diagram or task.

**Example:** An approval timeline labels a branch and its rejoin, avoiding a visual shortcut that skips review.

**Validation:** Have readers trace a real item through branches; record incorrect routes.

**Counterexample:** A smooth decorative line crosses a required decision and falsely implies it can be bypassed.

**Conflicts:** Prioritize truthful workflow relationships over attractive continuity.

**Evidence boundary:** Scholarly review sections inspected, not each original experiment; workflow design is a qualified extrapolation.

**Useful when:** Make a multi-step path or timeline legible.
