**Explanation:** Sustained work needs an appropriate challenge and control of interruption. Flow is a contextual lens, not a metric every screen must maximize.

**Signals:** An editor interrupts drafting with unrelated onboarding prompts.

**Interventions:** Retain working context and let nonurgent messages wait; keep necessary warnings timely.

**Limits:** A consequential interruption may be necessary; uninterrupted use is not always the user's goal.

**Example:** An author can finish a paragraph before viewing optional tips while a true save conflict stays actionable.

**Validation:** Observe interrupted/resumed work and missed consequential states, including user control over prompts.

**Counterexample:** Suppressing a failed-save warning preserves concentration while risking lost work.

**Conflicts:** Task integrity and informed control outrank uninterrupted engagement.

**Evidence boundary:** Editorial framework inspected; no flow state or engagement improvement has been measured here.

**Useful when:** Reduce avoidable interruption during sustained creation work.
