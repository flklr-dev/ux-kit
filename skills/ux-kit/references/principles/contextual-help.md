**Explanation:** Give task-focused assistance near the point of need while keeping deeper help discoverable.

**Signals:** A required format is explained only in an unrelated manual.

**Interventions:** Offer a concise example or explanation at the field, with more detail when useful.

**Limits:** Do not use hover-only help for essential instructions or force long tutorials on familiar actions.

**Example:** A tax-reference field provides the required format and an accessible explanation beside it.

**Validation:** Have users correct an unfamiliar value using available help without leaving or losing the draft.

**Counterexample:** A tiny tooltip containing the only required submission condition is inaccessible on some inputs.

**Conflicts:** Resolve brevity against necessary instruction, keyboard access and interruption.

**Evidence boundary:** First-party help heuristic inspected; placement and wording are original applications requiring task checks.

**Useful when:** Place useful assistance beside the task requiring it.
