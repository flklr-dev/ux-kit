**Explanation:** Introduce assistance when its purpose fits the task, retaining a useful first action and a return path to help.

**Signals:** An optional twelve-slide tour blocks writing the first note.

**Interventions:** Use a working sample or timely optional guidance; preserve entered work when help opens or closes.

**Limits:** Some consequential unfamiliar tasks need instruction before action; skipping cannot bypass necessary understanding.

**Example:** A note app lets people write immediately and offers photo guidance when Add photo is chosen.

**Validation:** Observe first useful action, later help discovery and recovery after dismissal.

**Counterexample:** Hiding a required safety explanation until after commitment would be too late.

**Conflicts:** Balance timely help against interruption and consequence-specific preparation.

**Evidence boundary:** NN/g's proactive/reactive help account inspected; the onboarding sequence is original application, not an activation guarantee.

**Useful when:** Introduce guidance when a feature becomes relevant.
