**Explanation:** People may try a useful action before reading instructions. Make safe initial action and relevant assistance available.

**Signals:** Writing the first note requires finishing an unrelated manual.

**Interventions:** Provide sensible starting state, clear affordances and accessible contextual help.

**Limits:** Do not conclude nobody reads documentation or omit preparation for serious consequences.

**Example:** A sample project supports a first reversible edit and points to guidance when needed.

**Validation:** Observe whether new users can begin, recognize limits and obtain help later.

**Counterexample:** A high-stakes import needs understood scope before execution even if users want to start quickly.

**Conflicts:** Balance learn-by-doing with consequence, access and required understanding.

**Evidence boundary:** Popular heuristic account inspected; no universal user behavior or activation result is asserted.

**Useful when:** Make first useful action possible without requiring a manual.
