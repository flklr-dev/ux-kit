**Explanation:** Closure concerns how incomplete contours can be organized perceptually. In products, test whether a partial shape remains interpretable.

**Signals:** A clipped outline icon is mistaken for a different command at small size.

**Interventions:** Prefer clear complete symbols or labels where the missing contour changes meaning; inspect contrast and scale.

**Limits:** Do not assume every person or display resolves an incomplete shape identically.

**Example:** A document action keeps a text label because a partially clipped folder icon is ambiguous.

**Validation:** Test identification at actual rendered sizes and relevant display conditions.

**Counterexample:** Using closure to justify cutting off a critical status word makes the state unreadable.

**Conflicts:** Readable labels and equivalent access override a stylistic preference for partial shapes.

**Evidence boundary:** The inspected review discusses closure in controlled displays; symbol comprehension here is unmeasured.

**Useful when:** Review whether partial shapes obscure icons or boundaries.
