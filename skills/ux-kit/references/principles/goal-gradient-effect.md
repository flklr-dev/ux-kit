**Explanation:** Progress communication should describe actual remaining work and a goal the user chose.

**Signals:** A setup starts at ninety percent before any required task is done.

**Interventions:** Use truthful milestones, explain optional work and allow returning to saved progress.

**Limits:** Do not fabricate completion, assume effort is linear or guarantee a motivation effect.

**Example:** A setup says Two required steps remain and separately offers optional reminders.

**Validation:** Compare the displayed state with every branch and ask what users believe remains.

**Counterexample:** Giving free artificial progress may make a process feel shorter while misleading about actual work.

**Conflicts:** Honesty, optionality and user goals govern progress presentation.

**Evidence boundary:** Popular account inspected; original motivational studies not verified. Artificial progress recommendation is deliberately rejected.

**Useful when:** Communicate truthful progress toward a meaningful goal.
