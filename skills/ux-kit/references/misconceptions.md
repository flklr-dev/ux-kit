# Limits on common shortcuts

Use named principles only when their conditions explain the actual difficulty. The following are not universal requirements:

- Seven plus or minus two as a menu, column or navigation limit.
- Three clicks as a maximum path length.
- Fewer steps or fewer choices always being easier.
- Minimalism or visual appeal proving usability.
- A clean automated scan proving accessibility conformance.
- A psychological effect guaranteeing a conversion gain.

The library does not revalidate the underlying research. Some entries explicitly qualify popular claims whose original studies were not inspected. For a consequential empirical assertion, inspect the relevant study, task, population and limits; a linked editorial account is not primary evidence.

| Shortcut | Better decision |
|---|---|
| Miller or working memory imposes an item quota | Distinguish recall, recognition and known-item lookup; keep necessary context visible and preserve useful comparisons. |
| Hick or choice overload means fewer always wins | Controlled response selection differs from search and preference formation. Clarify attributes and test the relevant decision. |
| Chunking means equal-sized boxes | Groups depend on learned relationships, vocabulary and task dependencies. |
| Gestalt proves comprehension | Cues can compete or imply false relationships. Check the actual layout, reading order and semantic association. |
| Fitts specifies every button size | Acquisition models differ from scoped standards and native units; measure the actual hit region and task. |
| Jakob requires copying a familiar pattern | Reuse conventions expressing the real action; reject inaccessible, deceptive or harmful behavior. |
| Serial position or distinctiveness guarantees recall | Check whether recall is necessary; stable lookup and available instructions may serve the task better. |
| Zeigarnik/goal gradient justifies pressure | Keep truthful progress and optional return. Never fabricate advancement or turn optional disclosure into an obligation. |
| Doherty gives a universal timing promise | Measure latency, acknowledge promptly and reconcile real outcomes. Do not fake progress, success or deliberate delay. |
| Aesthetic usability or flow proves performance | Separate impression, sustained work and actual completion/recovery. A consequential warning may need to interrupt. |
| Occam or minimalism means deleting controls | Remove irrelevant competition while retaining necessary decisions, comparisons and access. |
| Pareto predicts a fixed product ratio | Inspect actual frequency and impact; rare severe/access failures still matter. |
| Parkinson justifies arbitrary deadlines | Investigate process overhead without unnecessary time pressure; the popular dictum is not a scientific task-time rule. |
| Peak/end makes the middle unimportant | Inspect the complete journey. A pleasing ending cannot repair lost work or duplicate charges. |
| Tesler is a quantitative conservation law | Allocate mechanical work thoughtfully while keeping consequential assumptions and choices inspectable. |
| Postel permits loose parsing everywhere | Normalize clearly equivalent harmless formats; reject ambiguity and unsafe values, retaining server validation. |
| ARIA works by attribute presence | Use specified token values: empty aria-invalid defaults to false. Verify error and corrected states. |
| A disabled button proves concurrency safety | Exercise direct calls, pending overlap and actual effects; inspect operation scope and service reconciliation. |
| Citations or confidence numbers prove AI correctness | Trace each consequential claim to real support and verify whether uncertainty is calibrated for this task. |
| A favorable early experiment look proves a win | Use appropriate inference/stopping and guardrails. Safety stops and benefit claims differ. |

Use the [knowledge index](knowledge-index.json) for exact entry/source boundaries. Original applications are conditional practice. A named effect alone does not establish a defect, diagnose a user or prove a business outcome.
