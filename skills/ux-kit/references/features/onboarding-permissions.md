# Onboarding Permissions

Start with the first useful task and separate true prerequisites from optional setup. Choose the actual target OS/version and permission API before specifying prompts.

**Inspect:** What triggered this request? Can the core task continue after denial? Is progress truthful for optional/conditional work? Can dismissed help be found again, and can users understand necessary instructions without one sensory channel?

**Exercise:** Try fresh launch, skipped guidance, granted/denied/revoked access, return from settings and interrupted/resumed first work. A browser viewport is not native permission evidence.

**Preserve and resolve:** A camera-only capture genuinely needs camera access, but browsing/writing may not. Explain the unavailable feature and a real alternative; do not claim access exists after denial or block unrelated work.

**Select references:** Start with one or two entries for the unresolved decision; this list is a lookup, not a required reading bundle.

- [Contextual Permissions and Denial](../principles/permissions.md) — Keep permission-free tasks available when optional access is refused.
- [Progressive Onboarding](../principles/progressive-onboarding.md) — Introduce guidance when a feature becomes relevant.
- [Contextual Help](../principles/contextual-help.md) — Place useful assistance beside the task requiring it.
- [Goal-Gradient Effect](../principles/goal-gradient-effect.md) — Communicate truthful progress toward a meaningful goal.
- [Notification Consent and Control](../principles/notification-consent-and-control.md) — Support relevant notifications with understandable controls.
- [Equivalent Access to Non-Text Content](../principles/equivalent-access-to-non-text-content.md) — Provide useful equivalents for meaningful images, audio and video.
- [Cognitive Load](../principles/cognitive-load.md) — Keep a setup task understandable without remembering hidden values.
- [Uniform Connectedness](../principles/uniform-connectedness.md) — Connect related steps without implying a false dependency.
- [Serial Position Effect](../principles/serial-position-effect.md) — Investigate ordering where remembering a sequence actually matters.
- [Zeigarnik Effect](../principles/zeigarnik-effect.md) — Treat unfinished-task reminders as a hypothesis rather than a coercive device.
- [Spacing Effect](../principles/spacing-effect.md) — Plan repeated learning opportunities for an unfamiliar workflow.
- [Paradox of the Active User](../principles/paradox-of-the-active-user.md) — Make first useful action possible without requiring a manual.

**Report:** State the observed difficulty, smallest fitting change, tradeoff and actual checks. Separate source inspection, execution, browser/device evidence and human research. Do not invent a finding or claim an unmeasured benefit.
