# Search Filtering

Determine whether the task is a known-item lookup, exploration or comparison. Inspect actual index, terms, result data and existing expert use before reducing choices.

**Inspect:** Do labels predict useful destinations? Are active restrictions, counts and clear/reset behavior understandable? Are query rewrites visible/reversible and safe for exact IDs?

**Exercise:** Try realistic terms, typos, exact identifiers, combined filters, zero matches, pagination, selection, details and Back. Verify result relevance, selection membership and preserved context, not only rendering.

**Preserve and resolve:** A large searchable known-code list may serve experts well. Add clarity for unfamiliar choices without imposing a seven-item cap or forcing successful lookup through a wizard.

**Select references:** Start with one or two entries for the unresolved decision; this list is a lookup, not a required reading bundle.

- [Information Scent](../principles/information-scent.md) — Make link labels predict a destination’s usefulness.
- [Classification and User Vocabulary](../principles/classification-and-user-vocabulary.md) — Test category boundaries against how people organize the content.
- [Faceted Filtering](../principles/faceted-filtering.md) — Support useful combined filters and understandable result changes.
- [Search Reformulation and Recovery](../principles/search-reformulation-and-recovery.md) — Help users recover from misspellings and empty searches.
- [Back Navigation and State Retention](../principles/back-navigation-and-state-retention.md) — Return to the previous list without losing its useful state.
- [Preserve Useful Expert Complexity](../principles/expert-complexity.md) — Retain comparison information and efficient established workflows.
- [Bulk-Selection Scope](../principles/bulk-selection-scope.md) — Explain whether selection covers visible rows or every matching result.

**Report:** State the observed difficulty, smallest fitting change, tradeoff and actual checks. Separate source inspection, execution, browser/device evidence and human research. Do not invent a finding or claim an unmeasured benefit.
