# Perception And Grouping

Inspect which elements appear to belong together and whether that relationship is true. Check labels, boundaries, relative spacing and reading order before adding decoration. A visually grouped surface still needs accessible semantics and correct interaction. Review static grouping separately from motion and foreground behavior.

- [Common Region](../principles/common-region.md): Group a subscription’s price and terms within a clear boundary.
- [Proximity](../principles/proximity.md): Associate helper text with the field it explains.
- [Prägnanz](../principles/pragnanz.md): Reduce ambiguous visual organization without removing required information.
- [Similarity](../principles/similarity.md): Use consistent treatments for controls with the same role.
- [Uniform Connectedness](../principles/uniform-connectedness.md): Connect related steps without implying a false dependency.
- [Good Continuation](../principles/good-continuation.md): Make a multi-step path or timeline legible.
- [Closure](../principles/closure.md): Review whether partial shapes obscure icons or boundaries.
- [Figure–Ground Separation](../principles/figure-ground-separation.md): Distinguish foreground dialogs and background content.
- [Common Fate](../principles/common-fate.md): Use coordinated motion to communicate a genuine relationship.
- [Visual Hierarchy](../principles/visual-hierarchy.md): Prioritize decisions, supporting details and secondary actions.

Preserve successful behavior. Prefer scoped accessibility and platform requirements over a conflicting heuristic; report evidence limits.
